================================================================================
          Northtropic 智能学习与AI题库系统 - Windows Server 部署使用说明
================================================================================

一、适用系统环境
--------------------------------------------------------------------------------
1. 操作系统：Windows Server 2012 R2 / 2016 / 2019 / 2022 / 2025 或 Windows 10/11 (64位)
2. 架构要求：x64 (64位)
3. 依赖项说明：
   - 本安装包为独立自包含版本 (Self-Contained)，目标服务器【无需】安装 .NET SDK 或 .NET Runtime！
   - 内置 SQLite 数据库引擎、PaddleOCR 本地离线引擎及所有前端静态资产。

二、快速安装部署（只需两步）
--------------------------------------------------------------------------------
1. 将解压后的整个安装包文件夹复制到目标服务器的任意稳定目录
   （例如：D:\NorthtropicServer 或 C:\Services\NorthtropicServer，建议路径不要包含特殊字符与空格）

2. 鼠标右键点击【1-安装服务(以管理员身份运行).bat】，选择“以管理员身份运行”：
   - 程序会自动检测管理员权限并弹出安装向导。
   - 输入您希望开放的端口号（默认 5000，直接回车即可）。
   - 安装程序将全自动完成：
     * Windows 后台服务注册 (开机自启、崩溃自动重启)
     * Windows 防火墙入站端口规则自动放行
     * 启动后台服务并打印当前服务器在内网和公网的访问地址
     * 自动在浏览器中打开系统首页

三、访问方式
--------------------------------------------------------------------------------
1. 服务器本机访问：
   http://localhost:5000  或  http://127.0.0.1:5000

2. 局域网/互联网客户端访问（在其他电脑、手机或平板浏览器中输入）：
   http://<服务器的IP地址>:5000
   例如：http://192.168.1.100:5000

四、运维管理快捷脚本
--------------------------------------------------------------------------------
目录内提供了一套简易运维脚本，双击即可执行：
  - 【1-安装服务(以管理员身份运行).bat】：首次部署或迁移安装。
  - 【2-启动服务.bat】：手动启动后台服务。
  - 【3-停止服务.bat】：手动暂停后台服务。
  - 【4-重启服务.bat】：更新配置或维护时重启服务。
  - 【5-卸载服务(以管理员身份运行).bat】：注销 Windows 服务及防火墙规则（保留业务数据库文件）。
  - 【6-控制台调试运行.bat】：以黑窗口前台模式直接启动，便于排查异常或查看即时日志。

五、数据安全与备份迁移
--------------------------------------------------------------------------------
1. 业务数据库文件路径：
   app\northtropic_study.db
2. 备份方法：
   在维护期间（或服务正常运行时），直接复制 app\northtropic_study.db 文件到备份介质即可。
3. 数据迁移：
   将原系统的 app\northtropic_study.db 覆盖到新服务器的 app\ 目录下即可无缝迁移所有学员数据、错题记录与题库。

六、常见问题解答 (FAQ)
--------------------------------------------------------------------------------
Q1: 局域网其他电脑打不开页面？
A1: 请检查：
    1) 确认服务器上的 Windows 防火墙已放行相应端口（安装脚本已自动处理，若有第三方安全软件如安全狗、360，请在其中放行该端口）。
    2) 确认云服务器控制台（如阿里云/腾讯云/华为云）的“安全组”中已添加对应端口（如 5000）的入站规则。

Q2: 如何修改服务运行端口？
A2: 方法一：再次以管理员身份运行【1-安装服务(以管理员身份运行).bat】，输入新端口即可。
    方法二：打开 app\appsettings.json，修改 "Urls": "http://0.0.0.0:新端口"，然后运行【4-重启服务.bat】。

Q3: 如何在系统开机时无需登录用户自动启动？
A3: 本安装程序注册的标准 Windows 服务为“自启动（Automatic）”模式，服务器断电重启后，无需任何人员登录 Windows 桌面，系统就会在系统启动阶段自动加载并在后台提供服务。
